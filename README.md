# Personal Portfolio - Adrian Stanciu's Website
A modern, multilingual portfolio website. Built with the latest web technologies and deployed on Vercel.

### 🌐 **Visit the Site:** https://adrian-stanciu.vercel.app/

## Features
- 🌍 Multilingual support (English and Polish)
- 📱 Fully responsive design
- 🔍 SEO-friendly structure
- 📬 Functional contact form powered by EmailJS

## Tech Stack
- Next.js 16
- React 19
- TypeScript 5
- Tailwind CSS 4
- EmailJS (contact form integration)
